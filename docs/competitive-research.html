What KSH Is (and Isn't)

KSH is a generative MIDI effect — it does not make sound. It sits closest to the Max for Live lineage (ProbablyGEN, Euclidean tools) and pure MIDI sequencers (Stepic, 510k POLYLLOP), not to full drum machines (Playbeat, Triaz, DrumComputer, XO).

Core strengths today

Engine: source/engine/KickSnareHatEngine.* · UI: ui/

  • 8 source banks with Stack / Per-channel / Static generation + refresh windows
  • Rich per-step logic: probability, cycle gating (offset + inversion), rolls, velocity
  • Per-channel polymeter: loop length, reverse/ping-pong playback, source locks
  • Source editor + generated preview with stable assignments (edits don't gratuitously re-roll)
  • Realtime-safe snapshot playback ( port-plan.md )
  • Host macros automatable: rate, swing, velocity/timing humanize, device active
  • M4L-faithful modifier-key layer editing (velocity / cycle / probability / roll)

Bottom line: No single competitor matches KSH's 8-source generative architecture + source/preview split . Stepic and POLYLLOP are the strongest pure-MIDI threats on product completeness (export, presets, platform coverage). Playbeat/Triaz win on instant gratification and sound-in-the-box .

Highest-Value Additions (Prioritized)

P0 Table stakes for a commercial plugin

  1. MIDI / bar export to DAW

    Stub already exists: export_generated_bars returns false in source/KshUiBridge.cpp . Every serious competitor (Stepic, POLYLLOP, Playbeat, Cthulhu) offers drag-drop or print-to-clip. This is the single biggest workflow gap vs. the M4L original's LiveAPI clip export ( port-plan.md documents the intentional skip).

  2. Preset + pattern library

    Today: getNumPrograms() = 1. Competitors offer factory banks + user saves + MIDI-triggered pattern recall (POLYLLOP: 12 patterns/preset; Triaz: 12/preset; HY-SEQ32: 8 snapshots + chaining). Minimum viable: named full-state presets + 8–12 pattern slots with MIDI note switching (KSH already maps C0–G0 for source select — extend the model).

  3. Per-channel rate and swing

    KSH has global rate/swing only. Triaz and Playbeat allow independent lane timing — this is the #1 polymetric feature users cite in reviews. KSH already has per-channel loop length and playback mode; adding per-channel rate multipliers would close the gap without changing the product category.

  4. Per-channel MIDI channel routing

    All output is channel 1 ( source/engine/KshMidiPlayback.h ). Stepic, Nest, and Euclidrum route to multiple channels/CCs. Essential for hardware users and multi-instrument setups.

  5. Ship-ready product packaging

    macOS-only CI, no AAX, no signing, v0.0.1. Competitors ship Windows + AAX + preset ecosystems. This isn't a feature but blocks comparison in pro studios.

P1 Differentiators that deepen the generative niche

  1. Euclidean rhythm helper

    KSH's cycle gating is powerful but opaque vs. classic pulses/steps (Euclidrum, Rozeta, alkman's Euclidean Sequencer). A "fill N pulses in M steps" UI that writes cycle/cycleOffset would make polymeter discovery faster without replacing the existing model.

  2. Gate / note length per step

    Stepic and POLYLLOP expose duration/hold lanes. KSH schedules fixed note-offs from rolls but has no per-step gate. Adds expressiveness for hats, percussion, and melodic lanes if channel count expands.

  3. Per-lane MIDI CC output

    Euclidrum sends filter/decay CC per hit. KSH could output 1–2 CC lanes (e.g. hat openness, sample select) — high value for Elektron-style workflows without becoming a drum machine.

  4. Constrained randomize ("dice")

    Stepic's 200+ scoped randomizers and Playbeat's per-parameter dice are expected in generative tools. KSH has generative modes but no one-click "randomize this channel respecting locks/probability bounds."

  5. Expose channel count in UI

    Engine supports 1–8 channels; editor always renders full count with no control. Quick win for minimal patterns and mobile/smaller layouts.

P2 Performance and live use

  1. Pattern/scene morphing or A/B

    Crossfade or quantized switch between two full persistence snapshots (Nest scenes, POLYLLOP patterns). Fits KSH's generative identity for live sets.

  2. Choke / exclusive groups

    Open/closed hat mutual exclusion (Playbeat, TR-style sequencers). Drum-specific and commonly requested.

  3. MIDI learn on macros

    Playbeat and Stepic map hardware to randomize/switch. KSH's five APVTS params are automatable but not MIDI-learnable from the UI.

  4. DAW undo integration

    UI undo stack (100 entries) is lost on reload and invisible to host undo. Expected polish for a paid plugin.

P3 Probably out of scope (different product)

  • AI genre-based pattern generation (Playbeat) — large ML/content investment
  • Built-in samples/synthesis (Triaz, DrumComputer, XO)
  • Modular patch cables (Nest) — different UX paradigm
  • Scale/chord/harmony (Stepic, Cthulhu) — low value for kick/snare/hat focus

What Is Lacking (Honest Assessment)

Product gaps (users notice first)

  • No escape hatch to the DAW — can't commit generative output to a MIDI clip
  • No preset browser — every session starts from scratch or project state only
  • Global timing feel only — no per-lane rate/swing
  • Single MIDI channel out — limits hardware routing
  • Pre-release packaging — no Windows/AAX; no signed installer

UX gaps (power users)

  • Cycle layer is cryptic — Euclidean UI communicates polymeter faster
  • Channel count hidden — engine capability not exposed
  • No "inspire me" entry points — no presets, dice, or drift/mutation
  • Host undo disconnect — UI undo invisible to DAW

Architectural strengths to protect

Don't copy competitors blindly. These are real differentiators:

  • Source assignment stability — many randomizers re-roll on every edit; KSH's source/generated split supports iterative composition
  • Realtime snapshot model — ahead of most indie sequencers on audio-thread safety
  • Sparse v:1 JSON persistence — clean; don't bloat into thousands of APVTS params
  • Pure MIDI FX positioning — competing with Playbeat on samples would dilute the identity

Strategic Positioning Recommendation

Own: "The generative MIDI drum brain" — 8-source probabilistic sequencer that layers under any drum plugin or hardware, with the most sophisticated per-step gating in the MIDI-FX category.

Don't chase: Sample libraries, AI genre packs, or full drum-machine UX — that's a different market with entrenched leaders.

Close first: Export → presets/patterns → per-channel rate/swing → MIDI channel routing. Those four turn an excellent M4L port into a product that stands next to Stepic and POLYLLOP on a feature checklist.

Marketing angle competitors can't copy easily: Dual-pane source/generated editing with stable generative assignments, 8-bank stack modes, and cycle-gate depth — show side-by-side with Playbeat randomize (re-rolls everything) vs. KSH (compose sources, preview outcome, commit when ready).
